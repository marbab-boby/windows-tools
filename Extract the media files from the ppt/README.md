# Extract PPT Media

Pulls the original images and videos out of PowerPoint files.

## How to use
1. Copy `Extract PPT Media.bat` into the folder with the presentations.
2. Double-click it.
3. Choose **Images only**, **Videos only** or **Both**.

## Result
For each presentation you get a folder with the same name as the file,
containing the images and videos that were inside it, at their original quality.

## Good to know
- Works with `.pptx`, `.pptm`, `.ppsx` and `.potx`.
- Old `.ppt` files are skipped. Open them in PowerPoint and use **Save As .pptx** first.
- Close the presentation in PowerPoint before running, or it may not open.
- Does not need PowerPoint installed.
