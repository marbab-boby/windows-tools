# Export Slides as Images

Saves every slide of every PowerPoint in a folder as a picture.

## How to use
1. Copy `Export Slides as Images.bat` into the folder with the presentations.
2. Double-click it.
3. Choose the format:
   - **PNG**: sharpest, bigger files (best for text and maps)
   - **JPG**: smaller files (best for photos and WhatsApp)
4. Choose the size: 1280, 1920 (Full HD, recommended) or 3840 px wide (4K, for printing).
5. Choose whether to include hidden slides.

## Result
For each presentation you get a folder named `<presentation name> - Slides`
with files named `Slide 01.png`, `Slide 02.png` and so on.

## Needs
- **Microsoft PowerPoint** installed on the PC.
- If PowerPoint was already open, it is left open.
- Password-protected or damaged files are skipped.
